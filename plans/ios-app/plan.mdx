### Objective

Ship an iOS app for fileaway that a user can test locally in the free iOS Simulator first, then submit to the App Store without a rejection surprise. The app covers share-to-save from TikTok/Instagram plus full feed parity with the web app (category tabs, search, item cards with actions), against the **same Convex backend and accounts** the web app uses today. "Done" for v1: a dev build runs in the Simulator against the dev Convex deployment, share-from-Safari saves an item end-to-end through the existing Apify → Gemini pipeline, and every App Store checklist item below is implemented or staged.

The storyboard above shows the six user-visible states; the document below carries the technical plan. A few decisions are still open — see Open Questions at the bottom.

<Callout id="decision-stack" tone="decision">

**Stack: Expo (React Native) development builds, in `mobile/` inside this repo.** `convex/react` and `@convex-dev/auth` officially support React Native, so the existing queries, mutations, and email/password + Google/GitHub accounts work with the generated types from `convex/_generated/api`. Native SwiftUI was rejected because Convex Auth has no Swift client (hand-rolled token flows would be the riskiest item in the project); a Capacitor web wrapper was rejected for Guideline 4.2 "minimum functionality" rejection risk. Expo Go is not enough — share intent and Keychain storage need a dev client (`npx expo run:ios`).

</Callout>

### Verification

Local loop: `npx convex dev` (terminal 1) and `cd mobile && npx expo run:ios` (terminal 2). The end-to-end smoke that must pass before calling any milestone done:

1. Fresh Simulator install → sign up with email/password → feed loads live data from the dev deployment.
2. Share a TikTok URL from Safari → app opens, "Saved — processing…" toast, item appears in `pending`, then flips to `done` with extracted data as `processUrl` completes (watch the Convex dashboard logs).
3. Kill and relaunch the app → still signed in (Keychain persistence).
4. Settings → Delete account → confirm → Convex dashboard shows the user's auth record and all `savedItems` rows gone; app returns to sign-in.
5. Jest units for `extractValidUrl` and share-intent parsing run in the existing `tests/` setup.

Sign in with Apple gets the same smoke on a physical device immediately after Developer Program enrollment, before the TestFlight build.
